# WorkBuddy Manager（飞牛原生 fpk）

腾讯 CodeBuddy 账号池管理控制台，内置 OpenAI 兼容反代网关。

本包为**飞牛原生打包**：内置 Python 3.12 运行时、全部 Python 依赖与 workbuddy2api 上游网关二进制，
安装后不依赖 Docker、不需要系统 Python，也不联网下载依赖。

## 安装后

- 面板：`http://<NAS-IP>:7864/`（安装时可改端口）
- 首次启动用安装向导里设置的管理员密码登录（用户名 `admin`）
- 上游网关固定监听 `127.0.0.1:7865`，只供本机管理端调用，不对外暴露
- web 搜索：`POST /v1/tools/search`（`{"query":"..."}`），与模型接口共用同一把密钥，由上游网关按账号池轮转并处理配额冷却
- 2.11.18 起前端静态资源按 gzip 传输（`WB_GZIP_ENABLED=0` 可关闭），`/v1` 流式对话与面板 JSON 不压缩
- 2.11.22 起，账号、密钥、用量数据库与上游配置存放在**应用共享目录**：文件管理 → 应用文件 → wbmgr（`data/manager.db`、`upstream/`），可直接查看和删除；升级自动从旧私有目录迁移
- 2.11.21 同步上游 v2.11.20：修复「自定义」单日趋势图为空（#460）、模型中心剔除视频/音频/图片生成模型（#461），统计页新增「昨日」；网关二进制与 scripts 未变

## 与官方部署的区别

- 官方提供的是 Docker / systemd / Windows 安装器；本包是 fpk 重打包，账号、密钥、用量数据都放在应用共享目录 `/vol4/@appshare/wbmgr`（2.11.22 起；旧版在应用数据目录，升级自动迁移）
- 共享目录里的 `manager.db` 与 `upstream/auths/*.json` 含账号凭据，任何能打开文件管理的人都能下载或删除，请自行控制 NAS 账号权限
- 升级走应用中心，账号、密钥、配置与数据库保留
- 包内「一键更新」不适用（更新由飞牛应用中心负责）

## 使用边界

仅用于管理本人及亲属自愿授权的账号；禁止批量注册、账号交易、代注册、接码、盗号、
绕过平台风控，以及任何商业转售或盈利性用途。详见上游项目 README。
